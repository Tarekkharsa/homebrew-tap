# AgentStack Homebrew tap

Official Homebrew formulae for [AgentStack](https://github.com/Tarekkharsa/agentstack).

```sh
brew tap Tarekkharsa/tap
brew install agentstack
```

Release checksums are generated from the corresponding GitHub release assets.
For support and security reporting, see the [main repository](https://github.com/Tarekkharsa/agentstack#support).
